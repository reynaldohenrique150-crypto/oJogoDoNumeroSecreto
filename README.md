# 🔢 - O Jogo do Número Secreto

Este é um jogo interativo desenvolvido durante os cursos de Lógica de Programação da **Alura**. O projeto consiste em um jogo de adivinhação onde o usuário tenta descobrir um número secreto gerado aleatoriamente pelo computador, recebendo dicas se o número correto é maior ou menor que o palpite digitado.

---

## 🚀 Funcionalidades do Jogo

* **Geração Aleatória:** O sistema gera um número secreto dinâmico a cada nova partida.
* **Sistema de Dicas:** O jogo ajuda o jogador informando se o número secreto é maior ou menor que o chute atual.
* **Contador de Tentativas:** Ao acertar, o jogo exibe uma mensagem personalizada exibindo o número de tentativas que o usuário precisou para vencer (ajustando a concordância para "tentativa" ou "tentativas").
* **Interatividade:** Interface interativa baseada em manipulação de elementos da página ou caixas de diálogo.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura da página e exibição do conteúdo.
* **CSS3:** Estilização e identidade visual do jogo.
* **JavaScript (ES6):** Toda a lógica do jogo (estruturas condicionais, loops de repetição e manipulação de funções).

---

## 💻 Conceitos de Lógica Praticados

* Estruturas condicionais (`if` e `else`) para validação dos palpites.
* Estruturas de repetição (`while`) para manter o jogo rodando até o acerto.
* Manipulação de variáveis e operadores matemáticos (`Math.random`).
* Template Literals para strings dinâmicas (como exibir as tentativas).
